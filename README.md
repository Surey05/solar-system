## ✨ About the Project

Welcome to my **Interactive 3D Solar System Explorer** 🪐

This project is a browser-based visualization that lets you explore the **Sun, planets, and Moon** in an interactive 3D environment.

Move around the solar system, zoom into planets, rotate your view, and explore space without needing a spacecraft. 🚀

> **Built with curiosity, code, and a questionable amount of time spent looking at planets. 🌌😂**

---

## 🪐 Features

| 🌟 Feature                   | 🚀 Description                                                    |
| ---------------------------- | ----------------------------------------------------------------- |
| ☀️ **Sun & Planets**         | Explore the major objects in our solar system                     |
| 🌙 **Moon Explorer**         | Explore the Moon — my personal favorite ❤️                        |
| 🔭 **3D Navigation**         | Rotate, zoom, and move around the solar system                    |
| ✨ **Planetary Orbits**       | Toggle orbit paths for a better understanding of planetary motion |
| 🎮 **Interactive Controls**  | Use mouse, touch, and keyboard controls                           |
| 🌌 **Immersive Space**       | Explore the solar system in a 3D environment                      |
| 📱 **Responsive Experience** | Designed to work across different screen sizes                    |

## 🌙 My Favorite — The Moon

Every planet has something interesting to offer, but the **Moon gets a special mention**. 🌙❤️

I wanted the project to make it easy to get a closer look at our closest natural companion in space.

Because sometimes you don't need to explore the whole universe...

**The Moon is enough.** 🌙✨

## 🎮 Controls

### 🖱️ Desktop

* **Left Mouse Button** → Rotate
* **Right Mouse Button** → Pan
* **Mouse Wheel** → Zoom

### ⌨️ Keyboard

Use the available keyboard shortcuts to quickly navigate through the solar system.

### 📱 Mobile

Use **touch gestures** to rotate, move, and zoom around the scene.
